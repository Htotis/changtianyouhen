一、仓库设置（只需填一次）

Token 获取：GitHub → 头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token，只给这一个仓库的 Contents 读写权限（Read and write）。Token 只保存在你当前设备的浏览器 localStorage 里，本页面不会把它发给除 GitHub 之外的任何地方。

二、发布新章节

发布后 GitHub Pages 约 1–2 分钟生效，可先去仓库 Actions 页看部署状态。若章节号已存在，会先跟你确认是否覆盖。
